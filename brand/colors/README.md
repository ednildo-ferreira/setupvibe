# Paleta do SetupVibe

| Família | Base | Papel |
| --- | --- | --- |
| Petróleo | `#00161E` | estrutura, texto e superfícies escuras |
| Turquesa | `#2AD5BE` | terminal e vínculo com a Promovaweb |
| Azul-ciano | `#00B4FC` | infraestrutura e configuração |

No light mode, use acento textual `#075985`. No dark mode, use `#7DD3FC`.
A escala completa e os estados ficam em `palette.json`; os pares aprovados
ficam em `../accessibility.md`.
